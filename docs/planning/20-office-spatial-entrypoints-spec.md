# 20-office-spatial-entrypoints-spec.md: 공간 진입점 — 메뉴 기능의 씬 통합 (D34)

> **상태: 확정 (2026-07-21, D34)** — Wave 1~2 동시 착수(사용자 지시).
> 원칙: **공간은 진입점, 폼/상세는 오버레이 창**(D27 "문서 작성 폼을 뷰포트 안에 두지 않는다" 유지,
> D29 셸 단일화의 오버레이 창을 그대로 상세 화면으로 사용). 좌측 레일은 폴백으로 유지(발견성·접근성).

## 1. 인터랙션 모델

씬 오브젝트/존/아바타 클릭 → **SpotCard**(공용 미니 카드, 상단 중앙, 폭 288px) →
핵심 액션 1클릭(기록 추가·예약·입장·비우기) 또는 상세 열기(기존 라우트 = 씬 위 오버레이 창).
스테이지 빈 곳 클릭(이동)·X 버튼으로 닫힘. 카드 데이터는 열릴 때 on-demand 조회(기존 API 재사용, 신규 API 없음).

## 2. 진입점 매핑 (Wave 1~2)

| # | 진입점 | 카드 내용 | 액션 | API |
|---|---|---|---|---|
| W1-1 | **아바타 클릭**(타인) | 이름·팀·프레즌스 상태 | 채팅 열기(/chat) | /api/employees |
| W1-2 | **내 아바타/내 좌석 클릭** | 오늘의 업무 목록(≤4) + 나의 KPI(collaboration_score) | 기록 추가(/work-log) · KPI 상세(/kpi) · 내 자리로 걷기 · **자리 비우기**(통합) | /api/work-logs, /api/kpi-results |
| W1-3 | **방 라벨 클릭** | 오늘 이 방 일정(시간·제목·상태) | 예약(/meetings) · (진행중 시) 입장하기(D24 onJoinMeeting) | /api/rooms, /api/meetings |
| W1-4 | **게시판 핫스팟**(Reception 옆 액자) | 최근 공지 5건 | — (읽기 전용) | /api/notices |
| W2-1 | **서류함 핫스팟**(Pantry 옆 캐비닛) | 최근 보고서 5건(유형·상태) | 보고서 열기(/reports) | /api/reports |
| W2-2 | **Lounge 방 카드 확장** | + general 채널 최근 메시지 3건 | 채팅 열기(/chat) | /api/chat/messages?channel=general |
| W2-3 | **배포 존 라벨 클릭**(팀 존) | 존 이름·팀 | 업무현황(/work-status) · 팀 채팅(/chat) | — (링크 수준) |

핫스팟 = 씬 모드 한정 아이콘 칩(22px, 호버 확대+title, 좌석 마커와 동일 z(15000) 패턴).
게시판 n=(0.615, 0.27) · 서류함 n=(0.263, 0.35) — HORIZON 씬 가구 실측 좌표.

## 3. 좌석 프롬프트 정리

기존 seatPrompt의 release 모드(내 좌석 클릭 → 비우기 확인)는 **W1-2 카드로 흡수** — seatPrompt는
sit(빈 자율석 착석 확인) 전용으로 축소. 자리 비우기·여기 앉기는 카드 액션으로 이동.

## 4. OUT (이번 범위 제외)

- 설정 + 관리 6종(KPI관리·조직도·동기화·감사로그·공지관리) — 공간 은유 없음, 메뉴 유지
- 카드 내 폼 입력(메시지 전송·업무 작성 등) — D27 원칙, 상세 화면으로만
- 씬 내 신규 아트/오브젝트 제작 — 기존 가구 위 핫스팟 칩만(P2 게이트 별도)
- Wave 3(출장 오브젝트·프로필 사진 배지)는 후속

## 5. 수용 기준

- S1: 카드 6종(profile·myseat·room·board·cabinet·zone) 각 진입점에서 열리고 데이터 표시
- S2: 카드 액션 → 해당 라우트가 **씬 위 오버레이 창**으로 열림(씬/실시간 연결 유지)
- S3: 회의실 카드에서 진행중 회의 입장하기 → 기존 LiveKit join 흐름(D24) 호출
- S4: 자리 비우기가 카드에서 동작(구 release 프롬프트와 동일 API), 빈 좌석 sit 프롬프트 회귀 없음
- S5: 스테이지 클릭 이동·착석·독·존 호버(D33) 회귀 없음, tsc 0·vitest 무회귀
