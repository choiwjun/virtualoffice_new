# 19-office-ux-simplify-spec.md: /office 몰입 모드 & 시각 품질 개선 스펙

> **상태: 확정 (2026-07-21, D33)** — 00-decisions.md §N 등재 완료. P0 구현 착수.
> 근거: 2026-07-21 내부 비교평가("복잡함, 타사 대비 시각 퀄리티 낮음") + oVice 경쟁조사(동일자).
> 원칙: **아트 재생성은 마지막 수단.** 화면 구성(IA)·비율·소음 제거를 먼저 하고, 에셋 파이프라인 재실행(P2)은 별도 승인으로 분리한다.

## 1. 문제 정의 (증거 기반)

2026-07-21 실화면 QA(realtime-qa-runbook §2 절차)와 oVice 제품 UI를 나란히 비교한 결과:

| 관측 | 우리 /office | oVice | 판정 |
|---|---|---|---|
| 공간 캔버스 비중 | 뷰포트의 ~55% | ~90% | 🔴 공간이 주인공이 아님 |
| 동시 노출 UI 클러스터 | 9개(사이드바 17메뉴·2F도면 위젯·미니맵·배지 4개·존 라벨 7개·우측 3섹션·미디어바·회의 오버레이·상단바) | 3개(얇은 상단바·접이식 이용자 목록·컨텍스트 툴) | 🔴 "관리 콘솔 안의 게임" 인상 |
| 아바타 vs 네임플레이트 | 네임플레이트가 아바타 본체보다 큼 | 아바타(사진 원형)가 주, 라벨은 보조 | 🔴 시선이 라벨로 감 |
| 사람 인식성 | 스프라이트 실루엣 소형·유사 | 프로필 사진 원형 + 상태 링 | 🟡 누군지 즉시 안 읽힘 |
| 존 가독성 | 검은 라벨 필만 | 존 바닥 색면(회의실 녹색 등) | 🟡 공간 구획이 안 읽힘 |
| 씬 렌더 | 가구·구도·오클루전 준수, 그림자/톤 플랫 | 일관된 파스텔 아트 디렉션 | 🟡 "미완성 렌더" 인상 |

핵심 재해석: **"퀄리티 낮음" 체감의 상당 부분은 에셋이 아니라 ①공간 점유율 ②비율 ③UI 소음에서 온다.** 차별화 자산(운영 데이터 통합)은 유지하되, 표현 위치를 사이드바가 아니라 공간 안(자리 배지 등)으로 옮긴다.

## 2. 목표 / 비목표

**목표**
- G1. /office 진입 시 공간 캔버스가 뷰포트의 **85% 이상**을 차지한다.
- G2. 상시 노출 UI 클러스터를 **3개 이하**로 줄인다(상단바 · 하단 독 · 접이식 우측 패널).
- G3. 아바타가 네임플레이트보다 시각적으로 우세하다(플레이트 높이 ≤ 아바타 렌더 높이의 40%).
- G4. 멀리서도 "누구인지" 읽힌다(프로필 사진 요소 도입).
- G5. 존이 라벨 없이도 바닥 색면으로 구획된다.

**비목표 (이번 범위 OUT)**
- 씬 에셋 재생성·캐릭터 스프라이트 재추출(→ P2, 별도 승인)
- 운영 콘솔(업무관리·KPI 등) 화면 개편 — /office 한정
- 모바일 대응, 신규 기능(DM·반응 이모지 등) 추가 금지
- oVice식 사진-원형 아바타로의 전면 교체(스프라이트 캐릭터는 차별점으로 유지)

## 3. P0 — 셸 정리 (코드만, 에셋 무변경)

| # | 항목 | 스펙 | 수용 기준 |
|---|---|---|---|
| P0-1 | 몰입 모드 | /office 진입 시 좌측 사이드바 자동 접힘 → **아이콘 레일(≤64px)**, 호버/클릭 시 오버레이 확장. 다른 라우트는 현행 유지 | 캔버스 ≥85% 뷰포트. 사이드바 전 메뉴 접근성 유지(키보드 포함) |
| P0-2 | 하단 통합 독 | 좌상단 배지 4개(연결·내자리로·테마·상태) + 하단 미디어바 + 우하단 회의 오버레이 → **하단 중앙 단일 독**으로 통합. 연결 상태는 점(●)+툴팁, 오프라인 시에만 문구+다시연결 버튼 노출 | 상시 플로팅 요소 = 독 1개. 기존 기능(재연결·테마 순환·상태 변경·회의 입장) 전부 독에서 동작 |
| P0-3 | 도면 위젯 제거 | 사이드바 "2F 도면" 위젯 삭제, 층 전환(4F~B1F)을 미니맵 위에 흡수. 미니맵은 우하단 이동·접기 가능 | 위젯 중복 0. 층 전환 동작 회귀 없음 |
| P0-4 | 네임플레이트 다이어트 | 이름+상태점만(상태 텍스트·"(나)" 제거). 폰트 11px급, 반투명 배경. 본인 표시 = 텍스트 대신 **아바타 링 하이라이트**(기존 파란 링 유지·강화) | 플레이트 높이 ≤ 아바타 높이 40%. 본인 식별 1초 내(육안 QA) |
| P0-5 | 존 바닥 색면 | 존별 반투명 틴트 오버레이(회의실=그린, 포커스=퍼플, 라운지=앰버 계열; 씬 스프라이트 위 z-합성). 존 라벨은 **호버/축소 시에만** 표시 | 라벨 없이 존 구획 식별 가능(육안 QA). 오클루전 z순서 회귀 없음 |

## 4. P1 — 하이브리드 아바타 (P0 검수 후)

| # | 항목 | 스펙 |
|---|---|---|
| P1-1 | 프로필 사진 배지 | 스프라이트 머리 위(네임플레이트 좌측)에 **사진 원형 24px + 상태 링**. 사진 없으면 이니셜 원형(현 로스터와 동일 규칙) |
| P1-2 | 아바타 스케일 | 스프라이트 렌더 스케일 1.3~1.4× 상향. 클리어런스/충돌 반경(office2d 불변식 0.035<EPS 0.06<0.07)은 **불변** — 렌더만 확대 |
| P1-3 | 원거리 LOD | 줌아웃 시 스프라이트 대신 사진 원형만 렌더(oVice 인식성 차용) — 줌 기능 도입 시점에 연동 |

- 착수 조건: P0+P1 반영 후에도 시각 퀄리티 평가가 미달일 때
