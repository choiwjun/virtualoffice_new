## 📦 제작 형식 (전 에셋 공통 — 반드시 준수)

| 항목 | 요구 |
|---|---|
| **형식** | **`.glb`** (glTF 2.0 바이너리, 텍스처 내장), **오브젝트 1개당 파일 1개** |
| **스케일** | 실제 **미터** 단위 |
| **원점(pivot)** | **바닥 중앙**(바닥 z=0에 안착) |
| **텍스처** | PBR(baseColor·normal·roughness·metallic) 내장. ⚠️ **albedo에 조명·그림자 굽지 말 것** |
| **명명** | asset_id = **대문자·언더스코어**(예 `DESK_STANDARD_001`) — 05 정본 |
| **캐릭터** | 리깅된 glb **또는** T/A포즈 glb(리깅 없이 주면 Mixamo로 자동리깅) |

> **중요 — "키트(kit)" 개념**: 120개 가구를 다 만들 필요 없음. **재사용 모듈**을 만들어 씬에서 인스턴싱한다(책상 1종 → 8~12석에 복제). 아래 "수량"은 유니크 에셋 수(만들 개수)이지 배치 수가 아님.
