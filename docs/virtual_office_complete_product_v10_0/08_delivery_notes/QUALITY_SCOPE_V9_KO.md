# 품질 범위 안내

이 전달본에서 검증한 항목은 다음입니다.

- GLB 2.0 구조 및 파일 길이
- 스킨 존재 여부
- JOINTS_0 / WEIGHTS_0 속성
- 18개 휴머노이드 조인트
- 캐릭터별 12개 내장 애니메이션
- 별도 애니메이션 GLB 12개
- 엔진 연동 코드와 레지스트리 경로

첨부 디자인 시안은 렌더링·조명·후처리·수작업 모델링까지 포함된 비주얼 목표입니다. 컨셉 PNG는 실제 런타임 메시가 아닙니다. 상용 포토리얼 최종 품질을 위해서는 Blender/Substance 등에서 모델·UV·PBR 텍스처를 수작업으로 고도화하고, 엔진에서 HDRI, GI, SSAO, Bloom, reflection probe, soft shadow를 적용해야 합니다.
