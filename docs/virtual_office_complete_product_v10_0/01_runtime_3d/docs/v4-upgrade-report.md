# Virtual Office Production Asset Pack v4.0 — Hero Quality Upgrade

## 제작 완료
v4.0은 v3 패키지를 유지하면서 핵심 시각 품질을 좌우하는 히어로 에셋을 새로 고도화한 버전입니다.

## 주요 개선
- 리셉션: 개별 목재 슬랫, 곡면 대리석 데스크, 발광 로고, 하부 간접조명, 데스크 소품.
- 회의실: 투명 유리 패널, 금속 프레임, 파란 emissive outline, TV UI, 내부 회의 가구/인물.
- 워크스테이션: 4인 벤치 데스크, 플랜터 파티션, 듀얼 모니터, 키보드/마우스, 케이블, 컵/문서, 앉은 캐릭터.
- 라운지/팬트리: 블루 섹셔널 소파, 러그, 커피 테이블, 팬트리 바, 바스툴, 펜던트 조명.

## 한계
현재 환경에서 제작한 v4는 코드 기반 절차 모델링 GLB 고도화본입니다. 첨부 시안 수준의 완전 런칭급 포토리얼 마감은 Blender/Maya/Substance 기반 수작업 모델링, 베이킹, 캐릭터 스켈레탈 리깅, 엔진 조명/HDRI/SSAO/Bloom 세팅 단계에서 더 끌어올리는 것이 좋습니다.
