# Rigging & Animation v8

This folder adds production-ready developer handoff files for humanoid avatar animation.

- `characters_rigged_v8/*.glb`: skinned humanoid character models with embedded clips.
- `animations/humanoid/ANIM_*.glb`: retargetable skeleton-only animation clip GLBs.
- `animation-manifest-v8.json`: clip list and runtime loading metadata.
- `HUMANOID_RIG_MAP_V8.json`: bone names and humanoid mapping.

Coordinate convention follows the existing package: meter scale, Z-up, bottom-center pivot.
