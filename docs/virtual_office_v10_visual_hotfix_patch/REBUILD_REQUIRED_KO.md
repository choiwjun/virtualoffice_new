# 목표 시안 수준을 위한 재제작 대상

아래 항목은 런타임 설정만으로 해결되지 않습니다.

1. 캐릭터: 얼굴, 손, 헤어, 의상, 스킨 웨이트, 공통 리그 재제작
2. 리셉션: 곡면/베벨/대리석 UV/간접조명 구조 재제작
3. 태스크 체어: 메쉬 등판, 캐스터, 봉제 디테일, 베벨 재제작
4. 회의 테이블: 에지 베벨, 케이블 포트, 하부 프레임 재제작
5. 식물: 잎 메시/알파 카드/노멀 재제작
6. 유리 회의실: OPAQUE + transmission 기반 재수출, alpha blend 제거
7. 공간 씬: 회의실/라운지/워크스테이션 간 간격과 카메라 구도 재배치
8. 이름표: 거리별 숨김, 화면 겹침 회피, 오브젝트 뒤 occlusion 구현

교체 GLB는 기존 파일명과 asset_id를 유지하면 레지스트리, 배치 JSON, 좌석 앵커, 이동 시스템을 다시 만들 필요가 없습니다.
