1. P0 — 즉시 수정 필요 (실동작 버그 · 권한 결함)

1.1 권한 결함 (보안)

  1. KPI 권한 집합 오류 — kpi.py:45 _ADMIN_ROLES={"admin","leader"}:
    • superadmin이 KPI 조정·확정·이의 재검토에서 403 (모든 타 라우터는 superadmin 포함).
    • leader 팀 스코프 검사 없음 → 타 팀 임의 user의 점수 조정 가능 (06 §3.10: leader=자기 팀 한정).
    • finalize(확정)는 스펙상 admin 전용인데 leader 가능 (06 §3.10 매트릭스).
  2. ±10% 조정 한도 미강제 — kpi.py:122-124,266: AdjustRequest에 범위 검증 없음, 0→100 조정 가능 (08 §3.2). revisedscore(455-457행)도 동일. 조정 사유 ≥30자도 minlength=1로 격하.
  3. EOD 타인 명의 큐잉 — erp.py:295,326: user_id=body.user_id or user.user_id에 role 검사 없음 → 일반 직원이 타인 명의 ERP 일일보고 생성·전송 가능.
  4. 근태 API 미게이트 — erp.py:211-221: GET /api/attendances가 인증만 요구 → 일반 직원이 전 직원 출퇴근 시각 조회 가능 (06 §3.12: 관리자 전용).

1.2 실동작 버그

  1. 업무 '중단' 저장 실패 — tables.py:185-188 WorkLogStatus에 aborted 없음, UI(work-log/page.tsx:669)는 '중단' 옵션 제공 → 선택 시 422. (06 §3.6은 aborted 명시)
  2. 회의 예약이 사실상 불가 — 3중 결함:
    • room_id가 자유 텍스트(기본 'room-1')인데 백엔드는 UUID 요구 → 기본값 예약 항상 실패 (meetings/page.tsx:451,493). 방 목록/피커 API·UI 없음.
    • 충돌 검사(D23) 오작동 — meetings.py:197-203 or_() 3분기: 같은 방에 미래 회의가 있으면 그보다 이른 예약 전부 409.

  3. '진행중 화상회의' 오버레이 오표시 — OfficeShell.tsx:364-366이 미지원 쿼리 ?status=in_progress 호출 → 예정·취소 포함 모든 회의가 LIVE 표시.

2. P1 — 스펙 핵심 플로우 공백

  1. 회의 상태 전이 부재 — 시작/종료 엔드포인트 없음 → inprogress/completed 도달 불가, startedat/endedat 영구 NULL (meetings.py:220,466). join 시 상태·정원 검사 없음, leftat 미기록.
  2. 녹음/STT 동의 게이트 부재 (D20-b 컴플라이언스) — LiveKit 입장이 동의 확인 없이 연결(OfficeShell.tsx:287-297). '오디오 없이 참여' 거부 경로 없음. 참석자 본인 동의 상태 조회 API도 호스트 전용(consent.py:125-129) → 새로고침 시 동의 여부 유실. STT 게이트 의미도 역전: 스펙=거부자만 제외, 구현=1명 미동의 시 전체 403(meeting_minutes.py:400-420).
  3. 이의신청 7일 창 타이밍 역전 — 스펙: 공개 후 7일 내 이의 → resolved 시 확정. 구현: 확정 후에만 이의 접수(kpi.py:365-381), resolve 시 finalized_at 미갱신. 7일 무이의 자동확정 배치도 없음(scheduler.py). 확정 즉시 ERP push 적재(이의 창 개시 전) + 재조정 시 재push 없음.
  4. 자율좌석 상호작용 미배선 (06 §3.11) — 뷰포트에 좌석 렌더/클릭 없음. realtime sit_request 핸들러(OfficeRoom.ts:309-340)·백엔드 API(seats.py)는 준비됨 — 프론트만 공백. 퇴근/장기 away 자동 반납 경로 없음. realtime이 안내하는 확정 엔드포인트 POST /api/seats/claim도 실제(/api/seat-assignments)와 불일치(OfficeRoom.ts:340).
  5. 좌석 편집 draft 격리 붕괴 — 드래그/생성/삭제가 즉시 운영 seats 테이블에 반영(office-layout/page.tsx:154-183), 레이아웃 버전은 사후 스냅샷 → 검증·배포·롤백 상태머신(06 §3.3) 무력화. 롤백 백엔드는 있으나 UI 버튼 없음. draft 3D 프리뷰 없음. 팔레트 도구 4종만(Door/Spawn/Trigger 등 하드코딩 자동생성).
  6. 주간/월간 자동 리포트 미구현 — 06 §3.6: work_log 자동 집계(회의시간 합산·시간 기반 카테고리 분포·상태 요약 편집·CSV). 현재 reports는 자유텍스트 수기 작성으로 대체 — 스펙과 다른 물건. 신규 report와 KPI/EOD 체계 간 관계도 미정의(일일보고 이중 체계 위험).
  7. EOD 자동화 공백 (D17) — 배치가 push row 자동 생성 안 함(폼 미제출 날은 푸시 없음, eodpush.py:67-74), 주말·공휴일 스킵 없음, MAXRETRY=3 선언만 되고 미사용. 직원 본인 전송상태 확인 UI 없음(GET이 admin 전용), 재제출마다 중복 pending row.
