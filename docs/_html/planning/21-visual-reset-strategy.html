21 — 비주얼 전면 리셋 전략: 제로베이스 전수조사 결과 (D35 후보) v1.2

상태: 제안 — Phase 0 스파이크 육안 게이트 통과 후 D35로 00-decisions 등재 작성: 2026-07-22. 배경: PH+Mixamo 스파이크 반려 → "전면 리셋 OK, 처음부터 재검색, 상용화 수준" → 5트랙 병렬 리서치(픽셀 전수/고해상 2.5D/웹 3D/AI 생성/시장 해부). v1.1 (동일자): 사용자 사업 전제 명시 — "에셋으로 만든 가상사무실을 파는 게 아니라 B2B 플랫폼 자체를 판매" → 생산 방식을 정적 플레이트에서 모듈 카탈로그 합성으로 교정. v1.2 (동일자): 사용자 조건 — "찍어낼 수 있되 상용화 수준 퀄리티 필수" → §5-0 품질 규율 6원칙 신설, 게이트 ①을 벤치마크 비교(vs Kumospace/SoWork)로 조작적 정의, 미달 시 모듈 국소 재생성 2회 반복 규칙 추가.

§0. 사업 전제 (v1.1 신설 — 모든 판단의 기준)

판매 대상 = B2B SaaS 플랫폼. 고객사별 맵 제작 서비스가 아니다. 따라서 시각 시스템의 1급 요구사항은:

  1. 재현성: 신규 고객사의 레이아웃(인원·평면·좌석)이 무엇이든 수작업 아트 없이 데이터에서 씬이 생성되어야 함 — 고객별 AI 재생성·검수가 필요한 구조는 서비스업이지 플랫폼이 아님
  2. 확장성: 팀 증원·자리 이동·층 추가가 좌석 편집기(18-spec)·레이아웃 v2 배포·hot-swap(D12)으로 즉시 반영 — 이미 구축된 데이터 기반 아키텍처와 정합해야 함
  3. 브랜딩: 고객사 로고·컬러 반영 여지(틴트 가능한 요소) — 정적 원장 이미지는 불가
  4. 모트 구분: 비주얼은 도어 오프너(경쟁 데모에서 지지 않을 수준), 클로징 모트는 운영 계층(ERP 연동·KPI·근태/좌석·온프렘 배포) — 비주얼 투자는 "Kumospace급 첫인상"까지, 그 이상의 예술 투자는 ROI 없음

이 전제에서 "정적 AI 플레이트 1장" 방식(v1.0 초안)은 기각되고, 스타일 방향은 유지하되 생산 방식이 바뀐다.

§1. 결론 요약

전략 1 (권장): 하이엔드 2.5D 일러스트 × 모듈 카탈로그 합성 — "Kumospace 퀄리티를 ZEP 아키텍처로"

  • 모듈 카탈로그를 AI로 1회 생성(GPT Image 2/Nano Banana 2 Pro, 상업 라이선스 클린): 바닥/벽 타일·데스크·의자·회의 테이블·소파·화분·파티션 등 ~40–60종을 한 스타일 레퍼런스·한 조명 방향으로 생성, 1회 QA로 스타일 고정 → 이후 어떤 고객 레이아웃이든 합성 렌더(기존 z합성 오클루전 아키텍처·18-module M1 설계 그대로, 아트 소스만 교체)
  • 캐릭터 = 동일 스타일 레퍼런스의 일러스트 아바타(방향별 스틸 + sit/typing 포즈), 이동은 글라이드+밥 — 걷기 사이클은 폴리시드 계열의 상용 필수조건이 아님(oVice=사진 원형, Sococo=도트, Roam=버블로 상용 판매 중)
  • 스타일 통일 담보 = "한 모델·한 레퍼런스·한 조명"의 카탈로그 단위 1회 생성 — 단일 작가 원칙의 AI 구현. 고객별 생성이 없으므로 스타일 드리프트 리스크도 온보딩이 아닌 카탈로그 증보 시점에만 존재
  • 대형 고객 전용 커스텀 맵(정적 플레이트)은 유료 서비스 티어로 업셀(oVice 커스텀 배경 모델) — 플랫폼 기본은 어디까지나 합성

전략 2 (폴백, 확실성 최상): 픽셀아트 노선 — 전략 1 게이트 실패 시 전환(LimeZu/operationcwal/lennoxstudio, §4-1). 픽셀은 태생이 타일 합성이라 플랫폼 요구(§0)와는 자연 정합. 대신 한국 시장 커머디티 포지션 감수.

기각: 정적 플레이트 기본형(§0 위반) · 웹 실시간 3D(§4-4) · Synty(EULA) · 포토리얼(시장 부재) · 기성 벡터 캐릭터 팩(존재하지 않음).

§3. 캐릭터 병목의 해체

세 트랙 수렴: ①픽셀 팩조차 sit+typing+phone 완비 팩 없음(rx-pixel) ②일러스트+애니 기성 팩 부재, 외주 $400~800/캐릭터(rx-hires) ③AI 애니 사이클 프레임 일관성 미해결(rx-aigen).

돌파구 = 요구 재정의: 폴리시드 상용 계열은 걷기 사이클 없이 판매된다(oVice·Sococo·Roam). 방향별 스틸+글라이드+상태 포즈로 낮추면 AI 스틸 생성(사이클보다 훨씬 쉬움)으로 1인 조달 가능. 기존 이동계(A*·dt·Colyseus)는 무수정.

§5. 실행 계획

§5-0. 품질 규율 — "찍어내되 상용화 퀄리티" 6원칙 (v1.2 신설, 사용자 요구)

전제 인식: Kumospace·SoWork·ZEP 모두 모듈 합성 렌더다. 합성이라서 싸구려가 되는 게 아니라, 규율 없는 합성(PH 스파이크의 실패 = 스타일 혼재·렌더 이원화·조명 불일치)이 싸구려를 만든다. 아래 6원칙이 "합성인데 프리미엄"의 기술적 담보.
  1. 카탈로그 생성 규율: 전 모듈 동일 카메라각·동일 조명 방향(좌상 고정)·동일 팔레트·동일 텍스처 밀도. 레퍼런스 시트를 모든 생성 호출에 첨부, 그리드 일괄 생성(모듈 간 상대 일관성 확보) 우선
  2. 접지 내장: 모든 모듈에 소프트 컨택트 섀도 포함(또는 런타임 블롭) — PH 스파이크에서 확보한 그림자 파라미터 지식 재사용. "떠 있는 가구" 금지
  3. 글로벌 통합 레이어: 씬 전체 비네트+앰비언트 그라디언트+시간대 필터(기존 day/dusk/night 재사용)+존 틴트(D33 ROOM_TINTS) — 모듈 잔여 편차를 런타임에서 눌러 팔레트 통일감 생성
  4. 바닥·벽은 연속면: 타일 반복이 아니라 연속 패턴/9-slice+미세 노이즈 — "타일 티" 제거
  5. 반복 기계감 제거: 주요 모듈 2~3 변형(색·소품 조합) + 클러터 소품 카탈로그(머그·서류·러그·창가 화분) + 배치 시 클러터 자동 살포 규칙 — 같은 책상 12개가 "복붙"으로 안 보이게
  6. 벤치마크 비교를 게이트에 명문화: "예쁜가"(주관) 대신 Kumospace/SoWork 실제 스크린샷과 나란히 놓고 밀리지 않는가(비교 판정) — 상용화 수준의 조작적 정의
