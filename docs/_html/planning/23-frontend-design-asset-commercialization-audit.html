0. 한 줄 결론

엔지니어링 코어(기능·데이터·보안)는 22-doc대로 성숙하지만, "사서 쓰는 제품"의 겉면 — 상용 진입면(가입·온보딩·데모)·비주얼 생동감(아바타 모션)·디자인 시스템 단일성·멀티브랜드/다국어 — 이 통째로 비어 있다. 지금은 잘 만든 사내 도구의 프로토타입 UI다. 22-doc의 멀티테넌시(T0-1)와 본 문서의 진입면(E2~E4)·화이트라벨(A7+E5)이 같은 축으로 맞물려 있어, 이 둘을 함께 세우는 것이 "도구 → 제품" 전환의 본체다.

1. 통합 우선순위 로드맵 (축 교차 · 영향×규모)

22-doc의 Tier 0~3(백엔드)와 병렬 트랙. 접두어 F=프론트/제품면.

Tier F0 — 판매 데모가 성립하려면 (즉효·가시적, 대부분 S~M)

데모 URL 하나로 제품 강점을 보여줄 수 있게 만드는, 가성비 최상 묶음.

  1. B1 아바타 모션 부활 (S) — 지금 아바타는 좌표만 미끄러지는 무생물. 죽은 키프레임을 실제 연결하는 것만으로 "살아있는 공간" 인상. 가장 값싼 최대 임팩트.
  2. E8 리치 데모 시드 1커맨드 (M) — "빈 사무실+3명"을 "북적이는 가상회사(20+명·조직·공지·KPI·회의)"로. 세일즈 데모 성립 전제.
  3. A2 웹폰트 실제 로딩 (S) — Pretendard/Inter 선언만 하고 미로딩 → OS 기본폰트 렌더. 스크린샷/데모 품질 즉시 상승.
  4. D1 뷰포트 /office 전용 마운트 (M) — 유휴 유저의 Colyseus 슬롯·CPU·5인터벌·6 fetch 점유 제거(=22 T1-13). 안정·성능·동접 천장 동시 개선.
  5. E1 공개 랜딩/데모 라우트 (M) — 지금 /는 곧장 /office. 바이어가 제품을 발견·평가할 입구 신설.

Tier F1 — "제품"이 되려면 (온보딩·멀티브랜드 축 — 22 T0와 맞물림, L 중심)

  1. E2+E3+E4 셀프서브 온보딩 축 (L) — 가입→유저 생성→팀 초대. 없으면 깊은 admin 구성(좌석·조직도)이 전부 死자산. 22-doc T0-1(멀티테넌시)·T0-4(SaaS 계층) 위에 얹힘.
  2. 화이트라벨 = A7+A1 (CSS 변수 토큰) + E5 (브랜딩 UI) + 백엔드 Company 브랜딩 필드 (L) — 테넌트 브랜드 교체를 "변수 1세트 플립"으로. 프론트 CSS 변수화와 백엔드 Company가 함께 필요한 단일 워크스트림.
  3. E6 첫실행 셋업 체크리스트 + 최초 투어 (M) — 새 admin의 첫 5분을 성공 경험으로.

Tier F2 — 엔터프라이즈 판매 관문 (조달·계약 체크리스트, S~L)

  1. C1 i18n 카탈로그 (L) — B2B 재판매 전제인데 한국어 1개 로케일 락인. 추출비용이 기능마다 선형 증가 → 조기 착수.
  2. C4+C2+C3 토스트·다이얼로그 인프라 통합 (M) — native alert/confirm/prompt 치환, aria-live 확보. 이미 ScoreNoteModal 모범 사례 존재.
  3. C7~C10 + A11 접근성 베이스라인 (M) — 모달 dialog role·포커스 트랩, 아이콘/닫기 aria-label, input htmlFor, 차트 role=img, muted 대비 4.5:1. 대부분 기계적, WCAG 관문 통과.
  4. E11 동의/약관 게이트 + E7/E9 계정 셀프서비스(비번변경·찾기·알림) (S~M) — 백엔드 consent 테이블은 이미 존재(22 C1과 연결).

Tier F3 — 프리미엄 체감·확장성 (부채 상환·차별화, S~L)

  1. A4+A5 핵심 프리미티브(Modal·Button·Input) 추출 (L) — 12파일 복붙 #161F32 모달·손복사 버튼 흡수.
  2. B6+B9+B11+B13 에셋 절차++ 데이터화 (M) — 가구 레이어 캐시(테마 재렌더 프리즈 제거)·룸/재질/존 팔레트 데이터화(브랜딩 다양성).
  3. A9+A10 모션·아이콘 정제 (M) — 모달/팝오버/스켈레톤 트랜지션 + 이모지→단일 SVG 아이콘셋.
  4. D4+D5+D7 번들·RSC 위생 (S~L) — livekit 지연 로드, RSC 전환, next/image·next/font.
  5. A8+A12+D9 셸 분해·카드 단일화 (L) — 1837줄 OfficeShell 이중 렌더 브랜치 제거·하위 컴포넌트화.
