  2. 디자인 토큰(H1) — A0와 함께 확정.
  3. AI 서술(B1) — 키 확보 시. ERP 라이브(B2/B3) — OQ10 계정 확보 시.
  4. Godot/실시간/화상(C·D·E·S) — GPU·LiveKit·STT 환경 확보 후. Phase 순차(1→4→5).
