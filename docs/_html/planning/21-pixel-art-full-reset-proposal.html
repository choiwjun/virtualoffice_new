21 — 비주얼 전면 리셋 제안: Gather 계열 픽셀아트 (D35 후보)

상태: 제안 — 스파이크 육안 게이트 통과 후 D35로 00-decisions 등재 작성: 2026-07-22. 배경: PH+Mixamo 스파이크 사용자 반려("캐릭터·에셋 부조화, 사무실로 안 보임"). 사용자 지시: "전면 리셋도 괜찮아. 확실한 방법을 찾아서 고민해. 상용화할 수 있는 수준으로."

§1. 결론 요약

탑다운 픽셀아트(Gather 계열)로 씬·아바타 전면 리셋. 에셋은 LimeZu 단일 작가 팩 스택.

  • 팩: Modern Interiors(메가팩, name-your-price ~$5, 16/32/48px) + Modern Office Revamped($2.50, 오피스 300+ 스프라이트) + 캐릭터 제너레이터(Interiors 동봉)
  • 렌더 해상도: 48px 타일 + 정수 배율(pixelated) — 레트로가 아니라 "크리스프 픽셀"로
  • 기존 시스템 생존율 높음: 좌표계(lib/office2d.ts)·A*·이동 불변식·Colyseus·좌석·D33/D34 UX 전부 좌표 기반 → 유지. 교체는 씬 렌더 계층(플레이트→타일맵)과 아바타 시트뿐
  • Blender 렌더 파이프라인(EEVEE/Cycles·앵커 실측·오클루전 베이크) 전체 폐기 — 유지비 제로

§2. 왜 이것이 "확실한" 방법인가 (리서치 근거)

2-1. 시장 검증 — 상용 가상오피스에 포토리얼은 없다

2026년 현재 상용 플랫폼 상위권의 아트 스타일:

서비스스타일비고
Gather16px 탑다운 픽셀아트이 스타일 그 자체로 상용화 성공. 2026-02 창업자 AI팀 Figma行·비VC SMB로 분사했으나 제품·스타일은 유지, top-3 유지. 국내에 Gather 맵 제작 대행사(플러스마이너스픽셀)가 존재할 만큼 한국 B2B 수요 검증
SoWork2.5D 아이소(심즈/동물의숲풍)최상급 폴리시 — 단 전속 아트 인력 필요, 1인 재현 불가
Sococo/oVice플랫 벡터 도면미니멀 노선. 일러스트 일관성 확보가 1인에게 난제

공통점: 전부 게임풍 2D/2.5D. "게임처럼 보임"은 결함이 아니라 이 카테고리의 표준 문법. 우리가 실패한 지점(포토리얼 스캔 가구 혼합)은 애초에 시장에 존재하지 않는 노선.

2-2. 이번 실패의 구조적 해결 — 단일 작가 원칙

PH+Mixamo 반려 원인 3가지가 전부 원천 해소:

실패 원인 (07-22 진단)LimeZu 스택에서
가구 스타일 3계열 혼재(빈티지·미드센추리·앤티크)한 작가가 바닥·벽·가구·소품·캐릭터 전부 제작 → 조화가 기본값
캐릭터(EEVEE) vs 가구(Cycles) vs 배경(CSS) 렌더 이원화렌더 자체가 없음 — 전부 같은 팔레트의 픽셀 스프라이트
오피스 기호 전무Modern Office 300+ 오피스 전용(듀얼모니터·파티션·화이트보드·프린터·자판기·워터쿨러). 데모 육안 확인: "사무실"이 즉시 읽힘

2-3. 1인 개발 적합성

  • 아트스킬 병목([[free-asset-stack-2026]]의 결론) 제거: 필요한 아트가 전부 팩에 있고, 부족분(예: typing 애니 부재 시)은 16px 픽셀 수작업 — 유일하게 남는 아트 작업이 최소 난이도
  • 캐릭터 제너레이터 동봉(의상 100+·헤어 200·액세서리 80·피부 9): 팀원별 개성 아바타를 같은 스타일 안에서 무한 생성 — Mixamo 다인 캐릭터 문제(캐릭터별 재베이크) 소멸
  • 총 비용 $15 미만

2-4. 라이선스 (상용화 관점)

  • LimeZu: 상업/비상업 사용 명시 허용 · 에셋 재판매/재배포 금지 · 크레딧 필수(limezu.itch.io 링크) → 앱 크레딧 페이지에 표기. Synty류 "추출 방지 의무" 조항 없음 — 웹 서빙 관행상 안전(성의 표시로 아틀라스 병합 배포 권장)
  • Synty 기각 사유: EULA가 "이미지 파일로 렌더된 에셋 재배포 금지"+추출 방지 의무 → 웹에서 PNG 스프라이트 공개 서빙과 충돌. 상용화 시 법적 리스크
  • Kokoro Reflections(48px 고밀도) 보류 사유: 퀄리티는 높으나 캐릭터 없음 → LimeZu와 혼용 시 "작가 혼재" 실패 재발. 단일 작가 원칙 위반

§3. 기술 이행 계획

Phase 0 — 스파이크 (반나절~1일, 게이트)

  1. 팩 확보: itch.io에서 Modern Interiors(권장 $5) + Modern Office Revamped($2.50) — 사용자 결제 필요
  2. 48px 타일로 현 레이아웃(20×11.256m ≈ 0.5m/타일 → 40×23타일) 정적 목업 1장(ph.html 방식의 단일 HTML)
  3. 검증 항목: ①캐릭터 sit 4방향 여부 ②typing 애니 유무(없으면 sit+노트북 소품 or 6프레임 자작) ③회의실·라운지·팬트리 구성 가능 여부 ④48px 크리스프 판정
  4. 사용자 육안 게이트 — 통과 시에만 Phase 1. 통과 시 D35 등재

Phase 1 — 씬 리셋 (2~4일)

  • 맵 제작: Tiled(무료 에디터) → JSON → 런타임 로드. 본사 맵 1종(워크존·회의실 2·라운지·팬트리·폰부스)
  • 뷰포트 렌더러 교체: 타일맵 3레이어(floor / object / above) 캔버스 렌더. 오클루전 = above 레이어를 아바타 뒤에 드로우(행 기반 z) — 베이크·앵커 실측 전부 불필요
  • 좌표계 유지: 미터↔타일(0.5m) 매핑만 추가. A*·WAYPOINT_EPS·착석 게이트([[office2d-movement-invariants]]) 무수정
  • 아바타 교체: 제너레이터 산출 시트(walk/idle/sit/phone) → AVATAR_ANIM 프레임 수만 수정
  • 레이아웃 v2 배포·hot-swap(D12)은 맵 JSON 참조로 정합

Phase 2 — 상용 마감

  • 시간대 테마(day/dusk/night 런타임 필터) 재적용 — 픽셀에도 동일 적용 가능
  • D33 몰입모드·D34 SpotCard 정합 확인(좌표 기반이라 대부분 무수정)
  • 다인 아바타: 제너레이터로 팀원별 생성 + 프로필 연동

폐기 목록

  • tools/asset-gen/spike-scripts/(Blender 파이프라인) — 스파이크 기록으로만 커밋 보존
  • frontend/public/spike-kenney/ — 판정 완료, 삭제
  • HORIZON 플레이트/스프라이트 씬 계층 — Phase 1 완료 시 교체
