디자인 스타일 분석 & 디자인 시스템 (정본)

출처: 사용자 확정 디자인 시안 (KPI 업무 평가 시스템 통합 대시보드, 2026-07-08 첨부). 이 문서는 시안에서 추출한 디자인 언어를 토큰화한 정본이다. 모든 화면은 이 스타일을 따른다. 관련: photoreal-web-strategy.md(3D 뷰포트 렌더 전략), 06-screens.md(화면 구조).

0. 전체 인상 (Design DNA)

"프리미엄 다크모드 엔터프라이즈 대시보드 + 중앙 포토리얼 3D 오피스"

  • 테마: 다크 퍼스트(deep navy/slate). 밝은 데이터·아바타가 어두운 배경 위에서 돋보이는 구조.
  • 밀도: 정보 밀집형(data-dense)이되 카드·여백·계층으로 정돈 → 답답하지 않음.
  • 중심: 화면 상단 중앙의 포토리얼 아이소메트릭 3D 오피스가 시각적 주인공. 나머지 UI는 이를 감싸는 크롬(chrome).
  • 정서: 신뢰감 있는 SaaS 툴 + 실재감 있는 공간감. 차갑지 않게 — 3D 씬의 따뜻한 목재/식물 조명이 온기 담당.

1. 컬러 토큰 (Color Tokens)

hex는 시안 기반 추정치. 구현 시 최종 확정. CSS 변수/Tailwind 테마로 관리.

토큰Hex(추정)용도
--bg-base#0E1626앱 최하단 배경(딥 네이비)
--bg-surface#161F32카드·패널 기본 서피스
--bg-surface-raised#1E2940강조 카드·호버·드롭다운
--bg-surface-translucentrgba(22,31,50,0.72)3D 뷰포트 위 오버레이 패널(글래스)

1.5 데이터 시각화

  • KPI 게이지 링: --status-online(초록) 진행 + --border-subtle 트랙, 중앙 숫자 흰색.
  • Progress bar: --primary(파랑) 채움 + 어두운 트랙. 값 라벨은 우측 --text-secondary.

2. 타이포그래피

  • 국문 서체: Pretendard 권장(모던 한글 UI 표준, 무료·가변). 대안 Noto Sans KR.
  • 영문/숫자: Pretendard 내장 라틴 또는 Inter.
  • 스케일:
역할크기(px)굵기예
대형 지표(KPI 점수)40–44Bold(700)87
화면/섹션 제목16–18SemiBold(600)"나의 KPI 현황"
카드 타이틀14–15SemiBold(600)"오늘의 업무"
본문13–14Regular(400)목록 텍스트
라벨/메타11–12Medium(500)"업무중", "10:00"
  • 자간: 한글 기본, 숫자·영문 라벨은 약간 tight. 줄높이 1.4~1.5.

3. 레이아웃 & 그리드 (App Shell)

3분할 셸 + 중앙 상하 분할 (시안 구조 그대로):

┌──────────────────────────────────────────────────────────────────────┐
│  Header (로고+앱명 | 오피스선택 | 검색 | 알림·메시지 | 내 프로필)         │  ~56px
├────────┬────────────────────────────────────────────┬─────────────────┤
│        │                                            │                 │
│  Left  │        3D 오피스 뷰포트 (포토리얼)          │   Right Panel   │
│  Nav   │        + 아바타/프레즌스/미니맵/미디어바      │   사용자목록     │
│ ~240px │                                            │   일정/공지      │
│        ├────────────────────────────────────────────┤   ~320px        │
│        │  오늘의 업무 │ 나의 KPI │ 진행중 화상회의     │                 │
│        │  (3-panel dashboard row)                   │                 │
└────────┴────────────────────────────────────────────┴─────────────────┘
  • Left Nav: ~240px 고정. 아이콘+라벨 수직 메뉴. 활성 항목 = --primary-soft 배경 + --primary 좌측 인디케이터/텍스트. 하단에 내 프로필 카드(아바타+이름+상태+상태변경 버튼).
  • Center: 상단 3D 뷰포트(약 55~60% 높이) + 하단 대시보드 3카드 행.
  • Right Panel: ~320px. 리스트형 카드 스택(사용자 목록 → 오늘의 일정 → 공지사항).
  • 간격 스케일(spacing): 4 / 8 / 12 / 16 / 24 (px). 카드 내부 패딩 16, 카드 간 12~16.
  • 반응형: 데스크톱 우선(≥1440 최적). 좁아지면 우측 패널 → 접기, 대시보드 3카드 → 세로 스택.

4. 컴포넌트 카탈로그 (시안에서 관측)

컴포넌트스타일 규칙
카드/패널radius 14~16px, --bg-surface, 얇은 --border-subtle, 소프트 섀도우. 헤더(제목 + 우측 "전체 보기 ›")
버튼(Primary)radius 10px, --primary 배경, 흰 텍스트, 중간 굵기. hover 시 --primary-hover
버튼(Secondary/Ghost)투명/서피스 배경, --border-subtle 테두리, --text-secondary
아바타원형, 얇은 링. 상태 점(status dot) 우하단 오버레이(초록/빨강/주황)
상태 뱃지(pill)라운드 pill, 상태색 배경 소프트(15% 투명) + 상태색 텍스트. 예: ● 업무중(초록)
KPI 도넛 게이지원형 프로그레스 링(초록), 중앙 큰 숫자 + "/100", 두께 중간, 트랙 어두움
Progress bar(지표)가로 막대, --primary 채움, 우측 값 라벨(예 9/10)
리스트 아이템좌측 아바타/아이콘 + 텍스트 2줄(주/보조) + 우측 상태/메타. hover 하이라이트
층 선택기(Floor)3D 뷰포트 우측 세로 탭(4F/3F/2F/1F/B1F), 활성 = --primary 채움
미니맵좌하단 오버레이 카드, 조감도 라인 + 컬러 점(아바타/회의실), 확대/축소 버튼
미디어 컨트롤 바뷰포트 하단 중앙 필(pill) 바: 마이크·카메라·화면공유·이모지·더보기. 활성/음소거 색 구분
화상회의 타일참석자 그리드(2×2), 각 타일 하단 이름 라벨 + 상태, 하단 컨트롤(마이크·카메라·화면·나가기(빨강))
드롭다운/탭상단 언더라인 탭(전체/사무실/회의중/외근·출장), 활성 언더라인 --primary

5. 3D 뷰포트 아트 디렉션 (포토리얼)

세부 렌더 파이프라인은 photoreal-web-strategy.md. 여기서는 비주얼 톤만 규정.
  • 시점: 고정 아이소메트릭(약 30~35° 부감). 씬 전체가 한눈에.
  • 조명: 실내 따뜻한 키라이트(리셉션 목재월·식물) + 회의실 쿨 블루 네온 엣지(--accent-cyan)로 공간 구분. 소프트 섀도우 + 앰비언트 오클루전.
  • 재질: 사실적 PBR — 유리(회의실 유리벽·반사), 목재(리셉션), 패브릭(소파), 금속(집기), 식물 그린.
  • 깊이감: 은은한 depth-of-field(원경 살짝 흐림), 대비 있는 그림자. 배경은 Blender Cycles 오프라인 렌더 품질.
  • 아바타: 씬 조명에 정합되는 실시간 아바타(깊이합성으로 가구·유리벽 뒤 자연 가림). 머리 위 이름+상태 HUD 라벨(반투명 pill).
  • 공간 요소: 브랜드월(회사 로고), 오픈좌석 군집, 유리 회의실(대회의실/프로젝트룸), 라운지 소파존, 식물 데코, 층 표지.
  • 상태 시각화: 회의실 헤더 라벨("대회의실 · 8명 회의중"), 아바타 상태 점, 미니맵 색점.

6. 모션 & 인터랙션

  • 프레즌스 동기화: 아바타 이동은 Lerp 보간으로 부드럽게(끊김 없이).
  • 카메라: 검색/사용자 클릭 시 대상으로 부드러운 팬(pan). 층 전환 시 크로스페이드.
  • 호버: 리스트/좌석/회의실 hover 시 미세 하이라이트 + 커서 피드백.
  • 상태 전환: 뱃지 색 전환은 짧은 페이드. 알림은 슬라이드 인.
  • 깊이/글로우: 활성 회의실·선택 아바타에 은은한 글로우. 과하지 않게.
  • 원칙: 모션은 "정보 전달 보조"용. 장식적 과잉 애니메이션 지양(엔터프라이즈 톤 유지).

7. 톤 & 보이스 (마이크로카피)

  • 한국어 존댓말, 간결. 상태 라벨은 명사형("업무중", "회의중", "외근중").
  • 숫자/지표 우선 노출(KPI 87/100, "8명 회의중", "접속중 28명").
  • 시간 표기: 24시간제(10:00, 14:00). 날짜: YYYY.MM.DD.

8. 접근성

  • 다크 배경 대비: 본문 텍스트 --text-secondary 이상으로 대비 4.5:1 확보.
  • 상태를 색만으로 전달하지 않기 — 점 + 텍스트 라벨 병기(색맹 대응).
  • 키보드 포커스 링(--accent-cyan) 가시화. 3D 뷰포트 외 UI는 완전 키보드 내비 가능.

9. 구현 매핑 (참고)

  • CSS 변수 + Tailwind theme.extend.colors로 위 토큰 정의.
  • 컴포넌트 라이브러리: 공용 <Card>, <StatusBadge>, <Avatar>, <KpiGauge>, <ProgressMetric>, <ListItem>, <MediaBar> 등으로 추출(현재 페이지별 Tailwind 재구현 부채 해소).
  • 3D 뷰포트는 별도 R3F 컴포넌트(<OfficeViewport>)로 격리.
