# Character Assets v1.1 Patch

This patch replaces the placeholder character files with visible stylized humanoid T-pose GLB assets.

Included base assets:

- `models/characters/CHAR_MALE_001.glb`
- `models/characters/CHAR_FEMALE_001.glb`
- `models/characters/CHAR_AVATAR_VARIANT_001.glb` ~ `CHAR_AVATAR_VARIANT_005.glb`

Included static pose previews for male/female:

- idle
- walk
- sit
- typing

Important: these are static T-pose / pose-reference GLBs, not final skinned skeletal animation files. They are intended as development-ready visible character base assets and can be rigged later through Blender or Mixamo.
