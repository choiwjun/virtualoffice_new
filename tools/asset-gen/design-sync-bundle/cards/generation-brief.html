HORIZON 오피스 씬 재작업 브리프

목표: "Scene" 카드의 배치 도면과 동일한 배치로, "Brand" 카드 시안의 포토리얼 아이소메트릭 렌더 질감을 가진 오피스 씬 1장.

불변 계약 (지오메트리)

  • 캔버스 비율 1672 : 941 (좌표계 가로 20m) — 크롭·레터박스 금지
  • 카메라: 2:1 다이메트릭 아이소, 원근 왜곡 없음
  • 모든 가구는 배치 도면과 같은 위치·같은 footprint (충돌 폴리곤이 여기서 파생됨)
  • 보드룸 전면 유리 문 개구부(우하단 변), 미팅룸 전면 유리 문 개구부(좌하단 변) — 막지 말 것

스타일

  • 라이트 오크 우드 + 네이비 + 웜그레이, 소프트 데이라이트(좌상), AO, PBR 재질
  • 브랜드월: 우드 슬랫 + "HORIZON" 레터링(판독 가능)
  • 바닥: 베이지 대형 타일, 창: 소프트 스카이
금지(과거 사고 재발 방지): 인물·캐릭터, 이름표, 텍스트 라벨(브랜드월 제외), UI 요소, 미니맵, 화살표. 씬은 완전 무인 상태의 클린 플레이트여야 함.
