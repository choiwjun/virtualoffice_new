2. 벤치마크 — 이것이 "상용화 수준"의 조작적 정의

Kumospace 실제 제품. 분석 — 프리미엄 감의 출처: ①재질 텍스처(우드 바닥 결, 패턴 러그, 석재) ②식물·소품 밀도(빈 바닥 없음) ③소프트 드롭 섀도(전 가구 일관 방향) ④채도 액센트(옐로 소파·레드 러그·블루 체어) ⑤아바타 = 프로필 사진 배지(일러스트 캐릭터가 아님!). 시점은 텍스처드 탑다운(순수 평면도에 가까움).

게이트: 생성 시안을 이 스크린샷 옆에 나란히 놓고 밀리지 않아야 통과. "예쁘다" 자체 판정 금지.

3. 스타일 후보 — 시안 2방향 생성 후 사용자 선택

A. 텍스처드 탑다운 (Kumospace 동형)B. 소프트 아이소 2.5D 상향
순수 평면도 + 리치 재질. 벤치마크와 직접 비교 가능, 왜곡 없음, 좌표계 단순. 권장 우선현 HORIZON 시점 유지 + 재질·밀도·섀도를 벤치마크급으로. 공간감 우위, 난이도 높음

4. 아바타 — 사진 배지 (캐릭터 일러스트 전면 금지)

사람은 프로필 사진 라운드 타일 + 네임필 + 상태점으로만 표현한다(벤치마크와 동일, 레포 P1 계획과 일치). 이동 = 글라이드. 착석 = 좌석 위 배지 스냅. 캐릭터 휴먼 일러스트는 3연속 실패 지점이므로 그리지 않는다.

6. 품질 규율 6원칙 (21-strategy §5-0)

①전 요소 동일 조명 방향(좌상)·동일 팔레트 ②전 가구 소프트 섀도 내장(떠 있는 가구 금지) ③글로벌 그레이딩(비네트·테마) ④바닥은 연속 재질(타일 반복 티 금지) ⑤반복 기계감 제거 — 가구 변형·러그·식물·소품 밀도(벤치마크의 빈 바닥 없음 참조) ⑥벤치마크 나란히 비교로만 판정
주의: 재질 텍스처는 절차적 생성(그라디언트·패턴·노이즈)으로 — 외부 이미지 에셋 의존 금지(라이선스 0 유지).
