dynamic workflows 모드 (Workflow 도구 가용 시 0순위)

최신 Claude Code의 Workflow 도구가 있으면, 빌드 오케스트레이터는 Build/Eval을 분리된 context window로 격리하는 동적 워크플로우로 실행합니다. 이는 agentic laziness(부분 완료 후 종료) · self-preferential bias(자기 결과 편애) · goal drift(목표 손실)를 구조적으로 차단합니다. 없으면 기존 분산/단일 모드로 자동 폴백(구버전 호환).
