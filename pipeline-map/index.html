CASE 01

신규 프로젝트 · 귀납

백지에서 출발해 Socrates 라인으로 풀스택까지. 가장 표준적인 정방향 경로.

neurion → socrates → screen-spec → tasks → bootstrap → auto-orchestrate
CASE 02

가정 검증 · 연역

"될 거야"라는 가정을 의심으로 정련. Validation 실험 + Impact Trace 회귀 루프.

doubt → screen-spec → tasks → ★validation → build → ★impact
CASE 03

기존 프로젝트 통합

이미 만든 코드를 reverse로 spec화해 파이프라인에 역방향 합류. sync로 드리프트 관리.

reverse → specs/ → (신규기능) → tasks → auto-orchestrate
CASE 04

빌드 오케스트레이션 4종

단일 워커부터 cmux 멀티페인까지. 환경·규모로 고르는 빌드 실행기 비교.

auto-orchestrate · harness · harness-forge · cmux-harness
CASE 05

검증 · 자가개선 루프

다층 검증 → 실패 시 powerqa·systematic-debugging → autoresearch RSI.

verify → powerqa → systematic-debugging → autoresearch
CASE 06

통합 진입 (stargate)

체크포인트 상태머신 + 결정점 14개. 모든 케이스를 자동 분기로 묶는 오케스트레이터.

checkpoint → 분기 → … → resume / restart
